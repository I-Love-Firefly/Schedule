# 离线课程表模型选择记录

日期：2026-08-26

训练设备：NVIDIA GeForce RTX 5060 Laptop GPU（8150 MiB）

端侧目标：Android arm64，识别阶段断网可用。

## 已验证候选

| 方案 | 结果 | 结论 |
| --- | --- | --- |
| MiniCPM-V 4.6 1B 直接读图 | 零样本 JSON 合法率 0/6；微调后 5 个未见模板精确课程 F1 仅 0.0847 | 密集表格的二维关系不稳定，不允许直接写库 |
| Qwen3-VL-2B-Instruct 直接读图 | 会跨星期重复课程，负样本也可能误判；端侧体积和延迟更高 | 不进入产品管线 |
| ML Kit 离线 OCR + 几何解析 | 小字 OCR 和网格坐标可靠，异形表格的字段语义容易混淆 | 保留为定位依据和安全校验 |
| ML Kit + MiniCPM5-1B 文本结构化 + 几何纠错 | 模型能恢复大部分课程名称、教师、教室；几何解析负责星期/时间，模型重复和幻觉可被拦截 | **最终采用** |

## 最终架构

模型选择 **MiniCPM5-1B**（Apache-2.0），不是视觉模型。输入是 ML Kit 在手机本地得到的 OCR 文本块及其 0..1000 归一化坐标。模型只负责把二维文本关系整理成固定 JSON；星期、时间和写库许可仍由确定性代码复核。

选择它的原因：

- 1.09B 参数，Q4_K_M 成品约 656 MiB，可在主流 arm64 Android 手机上运行；
- 中文和英文课程字段均可处理；
- 不需要把图片上传到服务器；
- llama.cpp 原生运行时成熟，可由 .NET MAUI 通过 C ABI 调用。

训练数据为 600 条合成训练样本和 100 条隔离验证样本，包含中英文课程、星期表头、时间/节次轴、合并 OCR 行、坐标抖动和非周课表负样本。LoRA 共训练 600 步（0.2 + 0.8 轮），第二阶段训练损失为 0.0352。三条未见样本的自由生成课程 F1 仅 0.087，说明低训练损失并不代表二维关系已泛化，因此模型只能作为受约束的字段复核器，不能取代几何定位器。

## 已知边界与安全策略

完整周表一次生成较长列表时，1B 模型可能不及时结束 JSON 并重复项目。因此产品实现不会信任模型的列表终点：只恢复完整 JSON 课程对象，丢弃不完整尾部，按“星期 + 时间 + 课程名”去重，再由几何解析结果纠正星期与起止时间。

AI 只能补充与几何课程同星期、同课程名且能在 OCR 原文找到的教师/教室；它不能修改写库安全状态。以下任一条件成立时禁止批量写库，只展示结果供人工校对：

- 课程名无法在 OCR 原文中找到；
- 星期或 HH:mm 时间非法、起止倒置；
- AI 与几何解析的重合数量不足；
- 疑似重复、异常课程数量或非个人周课表；
- 本地模型 JSON 无法恢复。

纯视觉模型未达到原定的未见模板门槛，因此它只作为保留实验，不作为产品依赖。最终系统的可靠性来自 OCR、专用小模型、几何约束和写库闸门的组合，而不是单个模型的自由生成。

嗨！欢迎来到课表助手 2.1  (≧▽≦)/

这是一个为学生打造的免费小工具，
希望能帮你轻松管理每周的课程安排～

✨ 你能做什么？

▸ 从课程表截图调用 DeepSeek API 识别课程，不用登录教务系统，也不用再手动一个个输入啦！
	(第一版支持 Android 上包含完整星期栏和时间/节次信息的网格课程表；保存前请校对识别结果。)

▸ 手动添加课程也可以自己填写课程信息，支持连续添加多门课哦。

▸ 左滑删除课程 不想要的课程，轻轻一滑就能删除。

▸ 桌面小组件 Android 用户可以把小组件放到桌面，随时看当前/下一节课，再也不怕迟到啦～

🎨 换个心情？

设置页里目前有一些主题可以选：

  跟随系统 / 浅色模式 / 深色模式
  猛男粉 🩷 / 流萤青 🩵 / 爱上雷神 ⚡（慎用！）

👁️ 护眼小助手

切换到浅色主题时，如果传感器检测到环境比较暗，会贴心地弹窗提醒你注意眼睛哦～（仅 Android 设备支持此功能）

📱 技术栈

.NET MAUI | C# | MVVM | SQLite，使用设备端 OCR 校验和 DeepSeek 视觉 API 提取课程

💡 最终确认的课程数据只保存在手机本地。仅当你主动选择课程表截图进行识别时，图片和设备 OCR 版面信息会通过 HTTPS 发送至开发者运营的 justindividual.site 网关，再由 DeepSeek 官方 API 完成结构化识别；API Key 仅保存在服务器端，应用不需要你的教务系统账号密码。
所以请放心使用！ (๑•̀ㅂ•́)و✧

如果仍然不放心，其实这个项目还开源到了 GitHub 上，你可以直接下载整个项目，然后去质问AI："这个项目到底有没有偷我的数据"

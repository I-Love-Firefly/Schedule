感谢继续使用课表助手！本次更新包括：

• 新增课程表截图识别，可通过 DeepSeek API 提取课程。
• 识别结果可逐项修改、删除，确认后才会写入课表。
• 修复部分设备上课程时间换行、占用空间过大的问题。
• 修复清空课程后桌面小组件日期和星期不更新的问题。
• 升级 SQLite 与 OCR 组件，修复已知安全漏洞并改善兼容性。

隐私提示：仅当你主动使用截图识别时，所选图片和设备 OCR 版面信息会通过 HTTPS 发送至开发者网关，并由 DeepSeek 官方 API 完成识别。API Key 不会保存在客户端，最终确认的课程数据仍保存在设备本地。

不同学校的课表布局存在差异，请在写入前逐项校对识别结果。
